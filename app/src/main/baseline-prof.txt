# Hand-written starter Baseline Profile for FortressTV.
#
# Replace this file with the generated baseline-prof.txt from the "Generate baseline profile"
# workflow (or from a run of :baselineprofile on a configured device) once you have one.
#
# How the entries were chosen: by reading the start-up path, not by measuring. Every class named
# here is declared in a source file that runs between process start and the Home screen:
# MainActivity -> StartupWarmup -> FortressTVApp -> the stores it reads -> restoring the playlist,
# Xtream snapshot and EPG caches -> FortressLibrary -> HomeScreen.
#
# Format (human readable ART profile):
#   Lpkg/Class;                 load this class at start-up
#   HSPLpkg/Class**->**(**)**   compile every method of the class and of its nested and lambda
#                               classes (H = hot, S = used at start-up, P = used after start-up)
# Names are the original ones; R8 rewrites them to the minified names when the APK is built.
# A line that matches nothing is ignored.
